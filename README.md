## 📜 AWS Cloud Practitioner – Completed Certificates

### ✅ 1. Cloud Fundamentals Certificate

This certificate covers the foundational concepts of cloud computing and establishes the core knowledge needed for AWS.

**Key learning areas:**
- Understanding cloud computing models: **IaaS, PaaS, SaaS**
- Benefits of cloud: **scalability, elasticity, high availability, fault tolerance**
- Shared Responsibility Model introduction
- Basic architectural principles used in cloud platforms
- Global infrastructure overview: **Regions, Availability Zones, Edge Locations**
- Virtualization concepts and how cloud abstracts compute, network, and storage resources

**Skills gained:** Cloud basics, architectural awareness, cloud models, fundamental AWS vocabulary.

### ✅ 2. Introduction to AWS Certificate

This certificate introduces you to the AWS ecosystem and walks through the major components of AWS infrastructure.

**Key learning areas:**
- AWS Global Infrastructure: **Regions, AZs, Edge Locations, Data Centers**
- Intro to core AWS services:  
  - **Compute:** EC2 basics, instance types, AMIs  
  - **Networking:** VPC basics, subnets, route tables  
  - **Storage:** S3 overview, object storage concepts
- IAM fundamentals: users, groups, roles, policies
- High-level architecture building blocks
- How AWS achieves scalability and reliability

**Skills gained:** Understanding AWS ecosystem, navigating the AWS platform, basics of compute/storage/networking, IAM principles.
